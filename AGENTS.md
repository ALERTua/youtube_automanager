# youtube_automanager

A service that adds YouTube videos to the playlists of the user by rules.

## Project memory

The traps, the measured facts and the decisions with their reasons are in the project memory. Before you start a task, read this file: [.claude/memory/MEMORY.md](.claude/memory/MEMORY.md).

A fact that holds on every machine goes into `.claude/memory/`. A fact about one machine or one deployment does not go into this repository.
